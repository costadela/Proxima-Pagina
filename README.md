# 📚 Próxima Página

O **Próxima Página** é uma aplicação web para organização e acompanhamento de leituras pessoais. O projeto foi desenvolvido com o objetivo de praticar a construção de **APIs REST**, **operações de CRUD**, **gerenciamento de rotas** e manipulação de estado no frontend.

## 🚀 Tecnologias

- **Frontend:** React + TypeScript (Vite)
- **Roteamento:** React Router DOM
