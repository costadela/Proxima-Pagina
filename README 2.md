# 📚 Próxima Página — Gestão e Acompanhamento de Leituras

O **Próxima Página** é uma aplicação web para gerenciamento de leituras pessoais. O projeto permite explorar um catálogo de livros, organizar leituras em listas personalizadas e gerenciar o histórico de livros.

---

## 🚀 Tecnologias Utilizadas ate Aqui

- **[React](https://react.dev/)** + **[TypeScript](https://www.typescriptlang.org/)**
- **[Vite](https://vitejs.dev/)** (Build tool e servidor de desenvolvimento)
- **[Tailwind CSS v4](https://tailwindcss.com/)** (Estilização com utilitários)
- **[React Router DOM](https://reactrouter.com/)** (Roteamento client-side)
